## 26.1.0 — 回归纯粹编辑器

从这个版本起版本号改为「年份.小版本」。产品定位收敛为**纯粹的 Markdown 编辑器 + 轻量 AI 辅助**，公众号写作工作站、联网搜索、微信发布等附属功能整体移除；旧功能保留在 v1.9.0 发布包与 `backup/v1.9.0-before-rewrite-20260913` 分支。

### 下载

| 平台 | 安装包 |
|---|---|
| macOS Apple Silicon（M 系列） | `iML.Markdown.Editor-26.1.0-arm64.dmg` |
| macOS Intel | `iML.Markdown.Editor-26.1.0-x64.dmg` |
| Windows | `iML.Markdown.Editor.Setup.26.1.0.exe` |

安装包未做 Apple 公证，首次打开若提示「无法验证开发者」，在访达里右键应用选「打开」即可。

### 记笔记

- **斜杠插入菜单**：空行输入 `/` 插入标题、列表、任务、表格、代码块、公式、流程图、日期等
- **双向链接**：`[[` 弹出笔记候选，点击链接直达；目录面板底部显示反向链接
- **全文搜索**：`⌘⇧F` 搜整个笔记库，命中片段高亮
- **每日日记与模板**：`⌘⇧D` 打开今日日记；`模板/` 目录里的笔记可作新建模板
- 查找替换、`⌘K` 插入链接、`⌘P` 导出 PDF、侧边栏拖拽调宽

### 笔记库

- 「工作区」与「笔记库」合并：侧边栏即笔记库树，`⌘⇧O` 切换笔记库
- 目录监听外部改动（同步盘 / 其他编辑器），未保存的标签页用橙点提示
- 设置里一键把笔记库放进 iCloud Drive；重启恢复标签页与未保存修改

### 轻量 AI

- **本机模型**：模型配置里选「本机模型」，编辑器自动下载 llama.cpp 运行时（llama-server）与推荐的 GGUF 小模型（讯飞星火 X2.5 1.7B / 4B、面壁 MiniCPM5 1B / 2B、Qwen3-4B），按本机内存与核心数标注是否满足要求；断点续传、SHA256 校验、随客户端启动、思考模式、上下文长度、运行日志、测试连接；请求只发往 127.0.0.1
- 模型配置按「企业模型中转站 / 网络模型服务 / 本地模型（Ollama、LM Studio、llama.cpp）/ 本机模型」四类组织
- AI 气泡（续写、流程图、SVG、AI 图片）与选区润色 / 总结 / 扩写保持不变

### 修复

- 设为 `.md` 默认打开方式后双击文件，应用启动却不显示文件
- 打开子目录文件时工作区被挪到子目录；关闭最后一个标签页或新建文档时文件树消失
- 未命名文档的静默保存改为等有正文后再按第一行命名（AI 生成中、空文档不落盘），不再出现 `$$.md`、时间戳这类文件名
- 配置 / 关于 / 快捷键改为主窗口内的浮层，Dock 与调度中心里只有一个窗口
- 首次安装或升级后自动展示「新特性介绍」，帮助菜单里可随时再看
- `⌘E` / `⌘⇧S` 与编辑器内建快捷键冲突；`⌘H` 被系统占用导致替换无法唤起
- Dock 图标比其他应用大一圈

### 工程

- Vitest（94 个用例）与 ESLint；富文本按块增量序列化；TiptapEditor 拆分模块；内联样式收口为 CSS 类
- CSP 去掉 unsafe-eval，Mermaid 改 antiscript，预览与 SVG 经 DOMPurify 净化，API Key 经 safeStorage 加密落盘
- 新增 iPad 端骨架（SwiftUI + PencilKit，未编译验证）与手写旁挂文件格式规范 `docs/ink-sidecar-format.md`

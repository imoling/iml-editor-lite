## 26.4.0 — 本机智能，笔记不出门

这一版把「智能」又往本机推了一步：开会时**谁说的一眼看清**（声纹在这台电脑上算、只存在这台电脑上）；手机录的会议、课程音频**选个文件就转成笔记**，约 40 倍速，全程离线；一场转写就是一篇笔记，边听边记要点，正文里打个时间戳，点一下录音就跳到那一刻。和 26.3 的实时转写、整理纪要、问你的笔记一起，听、认、记、问，全都在本机完成，声音和笔记都不出门。

编辑器这边：从 Obsidian 搬来的笔记库**搬来就能用** —— `[[笔记#小节]]`、`![[嵌入]]`、别名、悬浮预览、未链接提及都认得；日历、全库待办、标签改名、快速捕获、属性面板这些最常装的插件功能直接内置；再加上命令面板、导出 Word / 长图。

### 本机智能：谁说的都认得，录音也能转

- **区分说话人**：每句话定稿时算一个声纹（可选下载，27 MB），够像就归给已有的人、不像就是新来的「说话人 N」；面板上一人一个颜色，点名字改名，改成已有的名字就是合并；「这是我」记住你的声纹，以后每场自动标成「我」。放进笔记和交给模型整理的纪要，每句前面都带名字
- **转写一段录音**：手机录的会议、课程音频（m4a / mp3 / wav / flac / ogg / webm）选一个文件就转，约 40 倍速；和现场转写一样新建一篇笔记、原录音拷到笔记旁边，点句子回听、区分说话人、整理纪要都能用。单个文件先限 90 分钟
- **一场转写 = 一篇笔记**：点开始就新建一篇会议记录并打开（也可以记在当前笔记里），停下来全文和录音自动写进去；转写时 `⌘⇧L` 在光标处打一个可点的时间戳 `[mm:ss]`，点一下录音跳到那一刻。关掉这一场的笔记就等于结束转写，正在录的时候会先问一句

### 链接织完了

- **`[[笔记#小节]]`、`[[#本篇小节]]`、`[[笔记#^块]]`** 都能跳到位；输入 `[[笔记#` 会列出这篇的小节供选。以前点 `[[笔记#小节]]` 会新建一篇叫「笔记#小节」的笔记，这个老毛病一并修了
- **`![[嵌入]]`**：笔记、小节、块、图片、音频、视频都能就地渲染（视频可以直接播放；PDF 显示成文件卡片）。图片按文件名在整个库里找；嵌入套嵌入有循环保护
- **别名**：属性里的 `aliases` 参与链接解析、`[[` 补全（写成 `[[文件名|别名]]`）和 `⌘T` 快速打开
- **悬浮预览**：鼠标停在 `[[链接]]` 上就能看到那篇的开头，不用点过去；设置里可以关
- **未链接提及**：反链面板里列出正文中提到了这篇笔记名字、但没加链接的地方，点「链接」就地改成 `[[ ]]`，写盘前会核对原文位置
- 顺带修了目录面板的老问题：同名标题总是跳到第一个

### 命令面板 `⌘⇧P`

- 所有菜单里的动作都能搜到：中文、拼音首字母（`dc` → 导出）、英文都行；含「插入：表格 / 公式 / 提示块…」
- `⌘T` 快速打开也支持拼音首字母：敲 `xmzh` 直接找到「项目周会」
- 你原来的 `⌘P` 导出 PDF 没动

### 日历、待办、标签、捕获、属性

- **日记月历**：笔记库页底部钉着一个月历，有日记的日子有标记，点没日记的日子按模板新建
- **全库待办**：侧边栏新页「待办」汇总所有笔记里的 `- [ ]`；认 `📅 2026-09-30` 和 `[due:: 2026-09-30]`，按 已过期 / 今天 / 明天 / 7 天 / 以后 分段，其余按笔记分组；打勾直接写回原笔记那一行
- **标签改名 / 合并**：标签面板右键（或铅笔）就地改名，改成已有的名字就是合并；正文里的 `#标签` 和属性里的 `tags:` 一起改，没改到的行一个字节都不动
- **快速捕获**：全局快捷键 `⌃⌥N`（可改）随时弹一个小窗口，敲完回车追加到今天的日记，焦点回到你原来的软件
- **属性面板**：属性卡片可以直接编辑 —— 文本、数字、日期、勾选、列表芯片，加字段、删字段、改名；只动那个字段的几行，注释、空行、引号风格都不变。嵌套对象和多行字符串仍点「原文」改
- **文件树排序**：名称 / 修改时间 / 创建时间 × 升降序；中文文件名按拼音排（和访达一致）
- **同步盘一键**：设置 → 笔记库里列出本机装了的 iCloud Drive / 坚果云 / OneDrive / Dropbox 等，点一下把笔记库指过去；打勾的再点一下就改回原来的目录。注意这只是换个地方看，笔记文件不会自动搬过去

### 导出 Word 与长图

- **导出为 Word**（.docx）：标题、列表、表格、代码、引用、提示块、脚注、图片、`![[嵌入]]` 都转成 Word 自己的结构，WPS / Pages 也能开；公式以 LaTeX 原文保留
- **导出为长图**（PNG，发群里、发朋友圈用）：1500 像素宽，超长的自动分成几张，分张切在段落边界、不切断一行字；每张末尾带一个「来自 iML Markdown Editor」的角标
- 导出 PDF / HTML 时 `![[嵌入]]` 也会展开
- 导出成功后状态栏的提示带「打开」「在访达中显示」按钮，不用再翻文件夹找

### 还有这些

- 源码模式：`⌘D` 选中下一个相同的词；可选的 **Vim 键位**（设置 → 粘贴与输入，`:w` 保存）
- `⌥↑` / `⌥↓` 整块上下移动；脚注 `[^1]` 点击跳到定义
- **自定义样式**：笔记库里的 `.iml/snippets.css` 保存即生效（远程 `@import` 和远程 `url()` 会被屏蔽）
- **`iml://` 链接**：从别的软件唤起应用打开 / 新建笔记、开日记、快速捕获、搜索（安装版注册协议）
- 状态栏显示选中的字数；「新特性介绍」在热修版本（如 26.3.1）里不再是空的
- 修复：**切换标签页后按 `⌘Z`，上一篇笔记的内容会被撤销进当前这篇，并被自动保存写进文件** —— 26.3.1 及之前的版本都有这个问题，建议升级
- 修复：标题栏菜单打开后，点侧边栏 / 正文收不起来；应用自己新建并打开文件后马上打字，会被误标成「磁盘上已被外部修改」
- 已知限制：列表 / 标题折叠还没做；PDF 嵌入只有文件卡片；被嵌入笔记里的流程图在导出时不渲染；`.webm` 按音频处理

## 26.3.0 — 听得见，问得到

开会、听课时它替你记全文，你只管记要点；记下来的东西，之后用大白话一问就能找到。两件事都在这台电脑上完成，声音和笔记都不出门。

### 下载

| 平台 | 安装包 |
|---|---|
| macOS Apple Silicon（M 系列） | `iML.Markdown.Editor-26.3.0-arm64.dmg` |
| macOS Intel | `iML.Markdown.Editor-26.3.0-x64.dmg` |
| Windows（绝大多数电脑选这个） | `iML.Markdown.Editor-Setup-26.3.0-x64.exe` |
| Windows on ARM（骁龙本等） | `iML.Markdown.Editor-Setup-26.3.0-arm64.exe` |

安装包比上一版小了一大截（Windows 250 MB → 约 80 MB，macOS 153 MB → 约 90 MB）。未做 Apple 公证，首次打开若提示「无法验证开发者」，在访达里右键应用选「打开」即可。

### 实时转写：你记要点，全文它来记

- 侧边栏「转写」页点一下开始：边说边出字，停顿后定稿、自动加标点；中文、英语、粤语、日语、韩语都认得
- **识别在本机完成**，声音不上传。首次使用下载约 240 MB 的语音模型（SenseVoice），之后离线可用
- 转写时可以切到别的面板，状态栏的红点和计时一直在；停了可以接着录，时间戳接着往下排
- 转写全文以一个**折叠的块**放进笔记，你自己记的要点留在上面；这个块是标准 HTML，Obsidian、GitHub 里同样是折叠的，富文本和源码模式来回切也一个字不变
- 「存为新笔记」会建一篇带日期属性和「要点」小节的会议记录

### 回听：点哪句，听哪句

- 转写的同时留一份录音（一小时约 11 MB），跟笔记一起存在 `assets/`。不想留，在「智能 → 实时转写…」里关掉就只留文字
- 转写面板里有播放器；**点任意一句话，录音就跳到那句话开始的地方**，正在播的那句会亮起来
- 笔记里的转写块也带播放器，点块里的一句话同样能跳
- 录音只存在这台电脑上

### 整理纪要

- 转写停下后点「整理纪要」：结合你自己记的要点，列出「议题与结论」和「待办」，插在转写全文的前面
- 本机的小模型就能做（提示词专门为 4B 级的模型调过）；长会议自动分段提炼再合并
- 会上没说负责人和时间的待办，就只写事项，不编

### 丢不了

- 没放进笔记就退出了，下次打开转写和录音都还在，面板直接回到上次停下的样子
- 正在转写时退出应用，会先问一句
- 「清空」在有未保存内容时要点两下

### 问你的笔记 `⌘J`

- 用大白话问，不用想关键词：「上次周会定了哪些待办」「我记过哪些关于向量数据库的内容」
- 它先在笔记库里找出最相关的几段原文，再只根据这几段回答。**每个结论后面标着出处，点一下跳到原文那一段**；找到的几段原文先于答案出现，本机小模型想的那几秒你也不是干等
- 笔记里没写的，它会直说没有
- 可以接着追问；转写的内容同样问得到
- 需要先开启「相关笔记」（智能菜单），并配好一个对话模型 —— 还没配的话面板里会直接指路

### 智能 → 实时转写…

- **运行状态**：语音模型好了没、麦克风授权了没，一眼看清
- **语音模型**：下载、取消、删除
- **回听录音**：留不留
- **收音设备**：选麦克风（或跟随系统），点「试一下」看音量条；选定的麦克风拔掉了会自动退回系统默认，插回来再用回它。转写时一点声音都没进来，面板会提醒你检查麦克风

### 更轻、更快

- 安装包 Windows 250 MB → 约 80 MB，macOS 153 MB → 约 90 MB（之前界面用的库被重复打进去了一遍）
- Windows 改为每种架构一个安装包；绝大多数电脑选 x64
- 启动要加载的代码少了三分之一：流程图用到才加载；代码高亮收到 65 种常用语言（没收录的语言代码块照常显示，只是不着色）

### 更新提醒

- 发现新版本只主动提醒一次，之后靠「帮助」菜单上的红点，不再每次启动都弹
- 提醒里写明这一版更新了什么，并直接给出你这台电脑该下的安装包
- 应用一直开着不关的，每天也会检查一次

### 其它

- 侧边栏「问答」「转写」的空状态重做；问答给出可以点的例子
- 「智能」菜单：问你的笔记、写作助手、相关笔记、实时转写、AI 配图
- 修复：侧边栏功能往当前笔记里写内容时，如果光标正在编辑器里，写进去的内容不显示、再敲字还会被覆盖掉
- 已知限制：实时转写目前只收麦克风的声音，戴耳机开线上会议时对方的声音进不来（系统声音在计划中）；英文专有名词的识别还不够准；录音是 WebM 格式，macOS 自带的 QuickTime 打不开，用本应用、浏览器、VLC 或 IINA 可以

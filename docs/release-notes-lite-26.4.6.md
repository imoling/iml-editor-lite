## 26.4.6 — 和 Agent 一起改文档，谁的字都不丢

这一版修的来自 Issues 里的反馈（[#12](https://github.com/imoling/iml-editor-lite/issues/12)、[#14](https://github.com/imoling/iml-editor-lite/issues/14)、[#15](https://github.com/imoling/iml-editor-lite/issues/15)、[#16](https://github.com/imoling/iml-editor-lite/issues/16)），另外补上了两个基本功能：文件能移动，图片能复制。

### 外面改了，这边跟得上

- 没有未保存的改动：页面直接更新，不用切一下窗口，单独打开的文件也一样
- 这边也改过：编辑区顶部出现提示，可以选「载入新版本」「另存为」或「保留我的」，选之前自动保存不写盘。轻量版没有版本历史，选「保留我的」时外部版本会被覆盖
- 文件被移走或删除：不再自动写回原处

### 文件和文件夹能移动

打开文件夹后，拖到文件夹上或右键「移动到…」。文档里指向图片、附件的相对路径会跟着改；目标位置有同名文件时不覆盖。

### 图片能选中，也复制得走

点一下图片有选中框，`⌘C` 复制的是真图片，WebP 也会转成 PNG；文字连图片一起复制也带图。

### 查找、大纲、编号、链接

- 在查找框里点上下箭头或按回车，页面会滚到匹配项（#15）
- Windows 换行（CRLF）的文件，大纲不再是空的（#16）
- 富文本里列表中间插一段文字，后面的编号接着数；源码模式仍按文件里写的数字显示（#12）
- `asset.py`、`README.md` 这类文件名不再变成链接，打字和粘贴都一样；代价是打字输入 `github.com` 这种不带协议的域名也不再自动变链接（#14）

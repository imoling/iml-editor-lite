## 26.2.0 — 放心把笔记搬进来

这一版只做一件事：让你敢把 Obsidian、Typora、GitHub 里的笔记直接搬过来用 —— 写法都认得，文件不会被改花，改错了能找回来。

### 下载

| 平台 | 安装包 |
|---|---|
| macOS Apple Silicon（M 系列） | `iML.Markdown.Editor-26.2.0-arm64.dmg` |
| macOS Intel | `iML.Markdown.Editor-26.2.0-x64.dmg` |
| Windows | `iML.Markdown.Editor.Setup.26.2.0.exe` |

安装包未做 Apple 公证，首次打开若提示「无法验证开发者」，在访达里右键应用选「打开」即可。

### 保真：改一个字，只变一个字

- 富文本模式保存时，**没编辑过的块直接写回文件里的原文**：表格的对齐填充、列表用 `*` 还是 `-`、标题后空不空行、Setext 标题、CRLF、文件末尾的换行都保持原样。把笔记库放进 Git，改一个字后 `git diff` 里只有那一行
- 编辑过的块也不再被改花：`my_var` 不会变成 `my\_var`，`[1]` 不会变成 `\[1\]`，`C:\Users` 不会变成 `C:\\Users`
- 这些写法以前保存一次就丢，现在完整往返：删除线、`<u>` `<kbd>` `<sub>` `<sup>` `<mark>`、`==高亮==`、`<details>` 等 HTML 块、HTML 注释、脚注、带链接的徽章图、链接标题、`<url>` 与裸链接、表格对齐、嵌套任务、路径带空格的图片、`obsidian://` 这类应用链接
- 链接引用定义（`[ref]: url`）在编辑器里看不见，保存时无论如何都会留住

### 兼容 Obsidian / GitHub 写法

- **属性（frontmatter）**：文档开头的 YAML 显示成可折叠的属性卡片，双击改原文，注释与缩进不动
- **提示块**：`> [!NOTE] 标题` 渲染成彩色卡片，支持 GitHub 的五种类型、Obsidian 的扩展类型与折叠标记；在引用块里敲 `[!NOTE] ` 即可转换
- **标签**：`#标签`、`#项目/子项` 与属性里的 `tags:` 汇总到侧边栏「标签」页；点击正文里的标签直接筛选
- `[TOC]` 自动目录；行内公式 `$E=mc^2$` 直接渲染，单击修改；公式块的编辑入口修好了
- 斜杠菜单新增：提示块、警告块、目录、属性

### 版本历史 `⌘⇧H`

- 每次保存在本机留一个版本，逐行对比、一键恢复；恢复本身也进历史
- 别的编辑器或同步盘写进来的内容，在被覆盖前先留一份
- 历史放在应用数据目录，不污染笔记库和 Git 仓库；连续的自动保存合并成一个版本，保留最近 60 天

### 粘贴与图片

- 粘贴 / 拖入的图片自动压缩成 WebP（实测一张 3.7 MB 的截图 → 220 KB），存到笔记旁的 `assets/`，按时间戳命名
- 相对路径的图片现在能在富文本、预览、导出里正常显示
- 本地上传与 AI 生成的图片存成文件，不再把 base64 塞进正文
- 粘贴网址自动取网页标题；源码模式粘贴网页内容自动转成 Markdown（从代码编辑器复制的仍按纯文本）
- 视图 → 清理未引用的图片：列出没有任何笔记用到的图片，确认后移入废纸篓

### 轻量 AI

- **相关笔记与语义搜索**：「智能 → 相关笔记」里一键开启（独立于写作助手的模型设置）。26 MB 的本机嵌入模型（BGE-small-zh，可选 BGE-base-zh / Qwen3-Embedding 0.6B）给笔记库建向量索引，目录面板推荐「相关笔记」，全文搜索多出一栏「意思相近」。与本机模型共用 llama-server 运行时，笔记改动后自动增量更新，全程不出这台电脑
- 状态栏始终显示 AI 请求发往本机还是云端；设置里可一键关闭全部 AI
- 网络模型服务预设新增 **Agnes 国内站 / 国际站**（有免费额度，`agnes-2.0-flash`），排在最前；两站域名与 Key 各自独立
- AI 配图新增 **Agnes 国内站 / 国际站**（免费档 `agnes-image-2.0-flash`），全新安装默认选它；Key 与写作助手里同一站的 Key 通用
- **快速开始 AI**（帮助菜单）：把「本机模型 / Agnes 免费额度 / 已有服务」三条路摆在一起，本机模型那条一键装好运行时与最合适的模型。还没配过 AI 时，启动页和 AI 气泡会直接指到这里，不用敲完指令才发现没配

### 其它

- 专注模式 `⌘⇧.`：收起侧边栏和工具栏，当前段落以外淡出，光标行保持在屏幕中间
- 设置 → 正文排版：字体、字号、行距、页面宽度；拼写检查开关
- 源码模式左右滚动同步；预览里的任务列表有勾选框了；导出单文件 HTML
- 「智能」菜单按功能命名：写作助手（原「模型配置」）、相关笔记、AI 配图（原「图片生成配置」），每一项打开该功能的设置
- 写作助手的服务类型精简为三类，按推荐顺序排列：本机模型（全新安装的默认）、本地模型、网络模型服务；「企业模型中转站」去掉，任意兼容接口走网络模型服务里的「自定义」，26.1 的旧配置自动归类

### 修复

- 属性块 / 文末脚注被选中时打字会把整块替换掉
- 设置弹窗保存会冲掉 AI 配图的配置（含 API Key）
- 失焦自动保存会改写没动过的文件（修改时间变化，同步盘跟着重传）
- PDF 导出里本地图片与公式不显示
- 目录把 YAML 注释和代码块里的 `# xxx` 当成标题
- 应用被强制结束后 llama-server 成为孤儿进程

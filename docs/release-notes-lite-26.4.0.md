## 26.4.0 — 打开，写，保存

**iML 编辑器**是 iML Markdown Editor 的轻量版：一个纯粹的 Markdown 编辑器，像记事本一样用——双击一个 `.md`，改，保存，关掉。没有笔记库，没有 AI，没有后台进程；macOS 安装包 5 MB。要笔记库、双向链接、本机智能（转写、问你的笔记），用主版本；两个可以装在同一台电脑上。

### 下载

| 平台 | 安装包 |
|---|---|
| macOS Apple Silicon（M 系列） | `iML-Editor-26.4.0-arm64.dmg` |
| macOS Intel | `iML-Editor-26.4.0-x64.dmg` |
| Windows（绝大多数电脑选这个） | `iML-Editor-Setup-26.4.0-x64.exe` |
| Windows on ARM（骁龙本等） | `iML-Editor-Setup-26.4.0-arm64.exe` |

没有做 Apple 公证。macOS 首次打开若被拦下：系统设置 → 隐私与安全性 → 拉到底点「仍要打开」。Windows 需要 WebView2（Windows 11 自带；Windows 10 没有的话安装程序会帮你装）。

### 富文本与源码双模，保存时不改你的文件

`⌘E` 切换。富文本模式保存时，没碰过的块直接写回文件里的原文：表格的对齐填充、列表用 `*` 还是 `-`、Setext 标题、CRLF、文件末尾的换行都不动，`my_var` 不会变成 `my\_var`。用主版本或 Obsidian 写的文档拿来改也一样——`[[双向链接]]`、`![[嵌入]]`、`#标签` 这里不解析，但保存时逐字节写回。

### 该有的 Markdown 都有

标题、列表、任务列表、表格、代码高亮、引用、链接、图片、脚注、`> [!NOTE]` 提示块、`[TOC]`、属性（frontmatter）卡片、KaTeX 公式、Mermaid 流程图、SVG。行首 `/` 插入菜单，选中文字后的格式气泡，查找 / 替换，`⌥↑` / `⌥↓` 整块移动。粘贴的图片自动压缩成 WebP 存进文档旁的 `assets/`。

### 和记事本一样的规矩

永远有一篇文档开着，没有欢迎页：启动就是一篇空白文档，光标已经在里面。存不存你说了算：自动保存默认关闭，未命名文档从不会被悄悄建成文件，没保存的内容重启后还在。不在背后做事：不建索引、不留版本历史、不常驻进程、不申请任何设备权限。

### 导出 PDF、HTML、Word、长图

PDF 走系统的打印面板（在里面选「存储为 PDF」）；单文件 HTML 图片内联；长图 1500 像素宽，很长的文档自动分成几张、切在段落的边界上。

### 标签页与文件夹

标签页全套（`⌘W`、`⌘⇧T` 重开、`⌃Tab`、`⌘1`~`⌘9`、右键批量关闭），重启后恢复。`⌘⇧O` 打开一个文件夹，侧边栏就是一棵朴素的文件树：新建、重命名、创建副本、推入废纸篓，不建索引。
